## 0. 一句话定位

八十万禁军枪棒教头、天雄星「豹子头」——**长枪重骑、越战越怒**的正面攻坚型将领。视觉核心是「**压抑的怒**」：制式铠甲仍在，但已被风霜和冤屈磨出裂痕。

## 3. 外貌与配色

- **体型**：精壮挺拔，约 7.5–8 头身，宽肩窄腰，站姿稳如立柱（与鲁智深的「壮硕」区分：他是**匀称的武者**，不是巨汉）。
- **脸**：环眼浓眉、燕颔虎须（络腮短须）、面部线条硬朗；表情克制冷峻，不笑。
- **发**：束发戴小冠，鬓发利落。
- **配色**：
  - 主色：玄铁黑（甲）／霜白（披风、甲缘）
  - 点缀：朱红（枪缨、束带）
  - 金属：冷银（非黄金）
  - 禁用：艳金、花哨纹样（保持禁军制式的克制感）

## 4. 服饰与装备

- **制式精甲**：鱼鳞/山文甲片，有磨损与裂痕，肩甲略残（暗示流放经历）。
- **霜白战袍 / 披风**，下摆带风霜感的破碎边。
- **护腕 + 长靴**，便于长枪发力。
- **武器：丈八蛇矛**——长柄（约身高 1.6 倍），矛头呈蛇形弯曲，红缨在枪颈。
- **细节彩蛋**：腰侧可挂一枚旧制军牌（呼应禁军教头身份）。

## 5.1 多视图提示词（ImageGen 图生图，`image1` = `lin_chong_front.png`）

用途：为混元多视角图生 3D（`hy-3d-3.1`）补足背面与侧面信息。通用写法与视角选择策略见 `docs/pipeline-3d-asset.md` §4。

**固定尾段（三段都要原样带上）**：

```
人物本身的姿势、朝向、位置完全不变，仍是直立站姿、全身入镜、居中构图。
丈八蛇矛必须保持与参考图完全相同的持握关系：右手握住枪杆，长枪贴于身体一侧垂直竖立，
矛头朝上。绝对不得把长枪移到身后、不得悬空脱离手掌、不得改变持握手。
国漫卡通风格，cel-shading 平涂上色，墨线勾边，纯浅灰色背景，无场景元素，无阴影投影，线条干净利落。
```

**共同首段**：

```
【视角变更】同一角色的<视角>全身立绘，仅改变相机观察角度。
保持与参考图完全一致的角色外貌：束发小冠与鬓发、环眼浓眉与燕颔虎须、面部冷峻不笑、
玄铁色鱼鳞精甲的形制与磨损裂痕、略残的肩甲、霜白色破边披风、朱红束带与枪缨、冷银金属配件。
```

三段各自的开头（替换上句的 `<视角>`）：

| view_type | 首句写法 | 生成后评价 |
|---|---|---|
| `back` | `【视角变更】同一角色的正背面全身立绘，相机绕到人物正后方。` | ✅ 质量最优：披风朝镜头、蛇矛对称出现在画面另一侧，与正面图自洽 |
| `left_front` | `【视角变更】同一角色的左前方 3/4 视角全身立绘，相机绕到人物左前方约 45 度。` | ✅ 可用：转角保守但持握未漂移 |
| `right_front` | `【视角变更】同一角色的右前方 3/4 视角全身立绘，相机绕到人物右前方约 45 度。` | ✅ 可用：同上 |

**不采用**（实测失败，勿重试）：`left` / `right` 纯正侧视 —— 模型需凭空想象整个侧面与持矛关系，实测右视图把蛇矛挪到身后、脱离手掌悬空立着，与正面图矛盾。**宁要一致的近角，不要崩掉的远角。**

参数：`size=1024x1536`、`quality=high`、`input_fidelity=high`、`image1=assets/refs/lin_chong_front.png`。

产出落盘后**必做去水印**（ImageGen 无法关闭水印，部分批次会压右下角）：

```bash
python tools/nh3d_dewatermark.py --check assets/refs/lin_chong_*.png   # 先看
python tools/nh3d_dewatermark.py --safe-x 0.84 assets/refs/lin_chong_*.png  # 再执行（自动备份）
```

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切、无手部遮挡武器**。
- 长兵器（蛇矛）是重建难点：矛身需与身体**留有间隙**，避免粘连。
- 目标：GLB，静态网格 → 本地 Blender 绑骨 20 骨 + idle/attack/hit/skill 四动作，压贴图 1024²，覆盖 `assets/models/lin_chong.glb`。
- 身高归一化 1.75 单位（游戏层自动缩放）。
