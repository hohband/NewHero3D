## 0. 一句话定位

地速星「中箭虎」——一身旧箭疤的落魄猛将，张清的另一员副手。视觉核心是「**疤**」：面颊与臂上留着数处陈年箭伤，双手各持一柄短飞叉向两侧外张。

## 3. 外貌与配色

- **体型**：**精瘦结实**，约 **7.5 头身** —— 比龚旺**略瘦**，肩背线条硬朗但不如龚旺粗壮（这是区分二人的第二手段，第一是疤痕 vs 刺青）。
- **脸**：三十岁上下，**瘦长脸、鼻梁挺、下颌有须茬**，嘴角紧绷，**左颊一道陈旧箭伤疤痕**（浅色、已愈合），神情是「带伤的沉」。
- ⭐ **旧箭伤疤共数处**：**左颊一道**、**右肩与右上臂两三处**（陈年箭创的星状 / 线状疤）。
  - ⚠️ **不覆盖面部正面、不做鲜血淋漓的新伤、身上不插箭**。
- **发**：黑发束髻，戴一条**暗青头巾**（遮住额角，但露出脸颊的疤）。
- **配色**：
  - 主色：**暗青灰 / 水灰**（束身战衣）
  - 辅色：**灰褐**（皮革护具）
  - 点缀：**锈红**（叉头布条与腰带，暗示旧伤的血色，**低饱和**）
  - 金属：**暗铁**
  - **禁用**：金饰、亮银、鲜红（锈红必须压暗）

## 4. 服饰与装备

- **暗青灰束身战衣（短袖）**，外罩**褐色皮护胸与单肩护片**，**露出的右臂可见伤疤**。
- **宽护腕 + 布绑腿 + 皮靴**。
- **武器：飞叉** —— **短柄三叉（叉头三股、柄短，全长约 0.9m）**。
  - **姿态：双手各持一柄，向身体两侧外张**（与武松双刀同类姿态，**已实测可识别 ✅**），叉与躯干之间留出明显可见的间隙。
  - ⭐ 短柄 + 双持外张 = **本批最安全的兵器形态之一**。
- **细节彩蛋**：腰后一只**扁平皮袋**（装备用叉的，**不露叉尖**）。
  - ⚠️ 与龚旺同理：**不要在腰后插着叉** —— 会额外制造长条几何。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**。
- **优势项：双持短叉外张 + 垂臂握在腰胯高度** → 与武松双刀同形态（已实测成功），且比长剑 / 长枪短，远端离手仅约半臂。**这是本批最安全的兵器形态之一。**
  - 唯一不确定项：三叉的叉头有三个股，可能把 `dims[1]`（次长边）撑大、拉低长细比。若跑完被「丢弃」也**不必救** —— 叉紧贴在手里，最近骨就是手骨，动画里照样跟手。
- **风险项 1：「中箭」容易被生成成「身中数箭、血流满面」的战场瞬间。** → 提示词写死「陈旧愈合的箭伤疤痕、非新伤、无血迹、身上不插箭」。**出图后第一件事检查有没有多余的血或箭**，画成新伤这张图就废了。
- **风险项 2：与龚旺撞（同职业、同品质、同羁绊、同为投掷型）。** → **伤疤 vs 刺青** + **双持短叉外张 vs 单手持竖枪** + **略瘦 vs 略壮**。
- **风险项 3：腰后皮袋不要露叉尖**（避免在背后制造额外的长条几何）。
- 布料控制：**束身战衣，无下摆、无披风**。
