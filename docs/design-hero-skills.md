# 英雄技能设计（技能差异化 · 品质不设上限）—— 正式版

> **状态：✅ 已确认（2026-07-27）**，与 `design-auto-battle.md` 同为项目战斗方向的正式设计。
> 核心变更：**取消「品质决定上限」**。所有武将都能沿统一阶梯培养到最高品质；武将之间**只用技能组区分**。
> 配套主文档：`design-auto-battle.md`（刀塔传奇式横版自动战斗 · 正式方案）。本文是其中「游戏性关键」的技能与养成部分。
> 落地约束：技能效果串必须命中效果白名单（解析已迁移至 `src/shared/effects.js`）。本文标 ⚠️ 的是横版新增效果，需扩白名单 + 实现（清单见 §7）。
> 数据源现状：`data/units.csv`（30 武将）、`data/skills.csv`（每将已有 ult + act + 2×pas）、`data/proto_awaken.csv`（觉醒技，原型已落地）。

## 1. 品质模型重构：从「上限」到「培养阶段」

### 1.1 旧模型的问题
`units.csv` 现状：orange/purple/blue/green 既是稀有度又是强度上限——绿将（白胜/石勇/宋万…）永远弱，沦为狗粮。这与「技能差异化」目标冲突。

### 1.2 新模型
- 品质只是**初始获取稀有度**（收集难度/出货率），**不再锁强度**。
- 所有武将沿**统一培养阶梯**提升：`绿 → 蓝 → 紫 → 橙 → 红（无双）`。
- 每个阶段解锁的是**技能内容**，不是数值天花板：

| 阶段 | 解锁 |
|---|---|
| 绿（初始） | 普攻 + 小技能 |
| 蓝 | 解锁 **被动1** |
| 紫 | 解锁 **被动2** |
| 橙 | 解锁 **觉醒技**（英雄终极身份） |
| 红（无双） | 觉醒技强化 + 技能等级上限拉满 |

- **数值成长**走 `growth_curve.csv` 统一公式（同职业同曲线，不再有橙将天生面板高）。**差异化 100% 来自技能组**。

### 1.3 设计含义（重要）
平衡杠杆从「数值」整体移到「技能克制」。无上限环境里没有数值天花板兜底，**必须建立克制矩阵（§5）**，让任何强技都有克制手段，否则单技碾压无解。

## 2. 每英雄技能槽位

| 槽位 | 触发 | 说明 | 现状复用 |
|---|---|---|---|
| **普攻** | 自动 | 按职业/武器：近战 `adjacent` / 远程 `diamond`，自带 `rage(+20)` | `generic_melee/ranged` |
| **小技能** | 自动(CD) | 英雄专属；`auto_skill_policy.csv` 控制释放时机 | 现有 `act_*` 改造 |
| **大招** | **手动**(rage 100) | 英雄专属；玩家点放（刀塔灵魂） | 现有 `ult_*` 沿用 |
| **被动1 / 被动2** | 常驻/触发 | 被动2 培养到紫阶解锁 | 现有 `pas_*` 沿用 |
| **觉醒技** | 橙阶解锁 | **新增**，英雄终极身份标识 | 全新设计（本文 §4/§6） |

> 关键红利：刀塔传奇的「普攻 + 小技能 + 大招 + 被动」骨架，与你 `skills.csv` 现有的 `act + ult + 2×pas` **一一对应**。大部分技能**身份与效果串直接沿用**，本文主要做三件新增：① 横版效果适配；② 觉醒技；③ 小技能自动化 policy。

## 3. 横版效果适配（grid → 横版）

格子概念的效果需要重表达。原则：保留技能「身份与手感」，只换实现口径。

| 现有效果（grid） | 横版重表达 | 说明 |
|---|---|---|
| `teleport(n)` | ⚠️ `dash_back` 突进敌后排 | 刺客切后排（时迁/燕青） |
| `swap_position` | ⚠️ `expose` 把敌后排换到前排 | 暴露敌核心给集火（吴用/焦挺） |
| `move_mod / av_mod` | ⚠️ `haste / slow` 攻速增减 | 横版无格数移动，改为攻击间隔缩放 |
| `extra_action(n)` | ⚠️ `act_now` 立即获得一次行动 | 戴宗神行 → 队友立即出手 |
| `pull/push(n)` | `knockback(n)` 击退/拉近（身位） | 横版身位位移 |
| `summon(flag)+aura` | 沿用 | 旗帜变场上图腾，半径改身位范围 |
| 高地 `height_mod` | `row_mod` 前后排修正 | 前排承伤+、后排承伤−（主文档 §2.1） |
| 背刺/侧击 | 保留语义 | 背刺=背后方向攻击；侧击=前后夹击同一目标 |

**前后排纵深规则（补主文档 P1-4）**：
- 近战（`adjacent`）只能打**同排**目标 → 必须先进场或对方上前。
- 远程/AOE（`diamond/line/ring`）可**越前排**打后排。
- 刺客类（⚠️ `dash_back`）可突进敌后排 → 直接威胁法师/射手。
- 嘲讽（⚠️ `taunt`）强制敌方攻击自己 → 保护后排。

## 4. 旗舰英雄完整技能组（8 个 · 覆盖全 archetype）

> 每个给：定位 / 普攻 / 小技能(auto) / 大招(手动) / 被动1 / 被动2 / 觉醒技(橙阶)。效果串沿用现有语法；⚠️ 为新增效果。

### 4.1 林冲 · 豹子头（cavalry）— 物理爆发 / 残血收割
- 普攻：`phys_dmg(1.0);rage(+20)`（丈八蛇矛）
- 小技能「枪挑」：`phys_dmg(1.4);bonus_vs_high_def(0.4)`（CD2）— 戳高防前排
- 大招「风雪山神庙」：`phys_dmg(2.2);bonus_by_self_lost_hp(1.0);refresh_on_kill(1)` — **血越低越痛，击杀刷新再动**，残血收割核心
- 被动1「蛇矛如龙」：`phys_dmg(0.15)`（攻击追加）
- 被动2「冤恨难雪」：`buff(atk,0.08,1)`（受击攻+8%）
- 觉醒技「雪夜上梁山」⚠️：首次血量<30% 触发，`buff(atk,0.30,99);buff(crit,0.20,99)`（背水一战，呼应逼上梁山）— 高风险高回报的收割发动机

### 4.2 鲁智深 · 花和尚（vanguard）— 主坦 / 团控
- 普攻：`phys_dmg(1.0);rage(+20)`（水磨禅杖）
- 小技能「禅杖横扫」：`phys_dmg(1.0);knockback(1)`（CD3）— 推开突脸刺客
- 大招「倒拔垂杨柳」：`phys_dmg(1.2);pull(1);stun(1)` — **范围拉扯聚拢+眩晕**，把敌后排拽到前排集火
- 被动1「禅杖如山」：`def_up(0.15,1)`（回合开始）
- 被动2「醉拳」：`chance(0.35);phys_dmg(0.25)`（受击还击）
- 觉醒技「大闹五台山」⚠️：`taunt(2);buff(def,0.30,2)` — 嘲讽全体 2 秒并减伤 30%，主坦灵魂技，保护全队后排

### 4.3 武松 · 行者（infantry）— 单体爆发 / 精英杀手
- 普攻：`phys_dmg(1.0);rage(+20)`（雪花镔铁戒刀）
- 小技能「醉拳」：`phys_dmg(1.2);bonus_vs_elite(0.5)`（CD2）— 优先招呼精英
- 大招「醉打蒋门神」：`phys_dmg(0.9)x4;bonus_vs_elite(1.3)` — 四段连击，**对精英/BOSS 增伤**，打 Boss 专用
- 被动1「醉打」：`chance(0.3);phys_dmg(0.3)`（攻击追加一拳）
- 被动2「以血还血」：`chance(0.5);phys_dmg(0.15)`（受击还击）
- 觉醒技「血溅鸳鸯楼」⚠️：`execute_below(0.30)` — 对 30% 血以下目标直接斩杀，收割 Boss 残血

### 4.4 公孙胜 · 入云龙（strategist）— 法术 AOE / 团控
- 普攻：`mgc_dmg(0.9);rage(+20)`（松纹古定剑，远程）
- 小技能「掌心雷」：`mgc_dmg(1.2);paralyze(1)`（CD3）— 点控敌核心
- 大招「五雷天罡正法」：`mgc_dmg(1.5);paralyze(1)` — 大范围雷击+麻痹
- 被动1「天罡雷法」：`mgc_dmg(0.2)`（攻击附加雷伤）
- 被动2「驱邪缚魅」：`chance(0.2);bind(1)`（攻击束缚）
- 觉醒技「呼风唤雨」⚠️：`mgc_dmg(1.0);silence(2)` — 全场雷伤并**沉默全体 2 秒**，断敌方大招链

### 4.5 吴用 · 智多星（strategist）— 战术控制 / 运营
- 普攻：`mgc_dmg(0.9);rage(+20)`（两条铜链，远程）
- 小技能「扰乱军心」：`debuff_mgc(0.3,2);chance(0.5);bind(1)`（CD3）
- 大招「调虎离山」：`expose;debuff_mgc(0.3,2)` ⚠️ — **把敌后排核心换到前排**给集火，并谋略-30%
- 被动1「智多星」：`debuff_mgc(0.15,1)`（攻击降谋略）
- 被动2「谋定后动」：`buff(mgc,0.12,1)`（回合开始）
- 觉醒技「智取生辰纲」⚠️：`energy_drain(30)` — 抽敌方怒气最高者 30 怒，灌给己方怒气最低者，运营神技，加速己方大招链

### 4.6 花荣 · 小李广（archer）— 远程狙击 / 点名收割
- 普攻：`phys_dmg(0.9);rage(+20)`（天地日月弓，超远 diamond 3-5）
- 小技能「连珠箭」：`phys_dmg(0.7)x2;sure_hit`（CD2）— 必中二连
- 大招「百步穿杨」：`phys_dmg(2.5);sure_hit;target_rule(lowest_hp)` — **超远必中，狙杀血最少**，点名收割
- 被动1「小李广」：`buff(crit,0.1,1)`（回合开始暴击+10）
- 被动2「箭无虚发」：`chance(0.25);phys_dmg(0.2)`（攻击追加一箭）
- 觉醒技「梁山射雁」⚠️：`refresh_on_kill(1);rage(+50)` — 大招击杀后立即回到 50% 怒，**连狙**收割残局

### 4.7 李逵 · 黑旋风（infantry）— 狂战 AOE / 双刃剑
- 普攻：`phys_dmg(1.0);rage(+20)`（鬼王板斧）
- 小技能「板斧旋风」：`phys_dmg(1.1)x2`（CD3）— 近身横扫
- 大招「黑旋风」：`phys_dmg(1.3)x2;friendly_fire(0.3)` — 横扫两连击，**30% 误伤友军**，高风险高回报
- 被动1「杀气腾腾」：`chance(0.3);phys_dmg(0.25)`（攻击追加）
- 被动2「蛮皮」：`def_up(0.1,1)`（受击防+10%）
- 觉醒技「杀红眼」⚠️：`invuln_dying(2);lifesteal(0.3)` — 大招期间锁血不死（最低 1 血）+ 吸血 30%，狂战灵魂

### 4.8 安道全 · 神医（healer）— 治疗 / 驱散（唯一奶妈）
- 普攻：`mgc_dmg(0.8);rage(+20)`（银针，远程）
- 小技能「妙手回春」：`heal(1.5);dispel(2)`（CD2）— 治疗+驱散 2 减益
- 大招「华佗再世」⚠️：`heal(2.0);dispel(99);revive(0.3)` — **全队大奶 + 全驱散 + 复活最近阵亡友军 30% 血**，逆转战局的奶妈大招
- 被动1「神医圣手」：`chance(0.5);dispel(1)`（回合开始驱自身）
- 被动2「针灸续命」：`chance(0.4);heal(0.5)`（受击自疗）
- 觉醒技「妙手仁心」⚠️：`aura(hot+0.03,r99)` — 全场友军每 tick 回 3% 最大生命（持续治疗光环）

## 5. 克制矩阵（无上限时代的平衡基石）

没有数值天花板后，平衡靠「石头剪刀布」。每个强势技能都要有解：

| 强势流派 | 代表 | 被谁克制 | 克制手段 |
|---|---|---|---|
| 物理爆发/刺客 | 林冲、武松、燕青 | 高防坦克、嘲讽、护盾 | 鲁智深 `taunt`、宋万铁壁、⚠️`shield` |
| 法术 AOE | 公孙胜、吴用 | 沉默、驱散、切后排 | ⚠️`silence`、燕青/时迁 `dash_back` |
| 控制链（眩晕/麻痹/睡眠） | 鲁智深、公孙胜、白胜 | 免控、净化、驱散 | 安道全 `dispel`、⚠️免控觉醒 |
| 增益/光环流 | 郁保四、汤隆 | 驱散、偷取 | `dispel`、`steal_buff`（时迁） |
| 治疗/消耗流 | 安道全 | 斩杀、减疗、爆发 | 武松 `execute_below`、⚠️`heal_cut` |
| 召唤/图腾 | 郁保四 | AOE、优先拆图腾 | 公孙胜/李逵 AOE |
| 高回复狂战 | 李逵觉醒 | 斩杀、控制 | 武松/鲍旭 `execute_below`、鲁智深 stun |

> 落地：每个英雄进 `formation.csv` 时标注 `archetype`，AI（`auto_ai.js`）按克制矩阵做目标选择与大招时机（见主文档 §5.2 扩展）。

## 7. ⚠️ 需扩展的效果白名单（碰红线，须显式实现）

以下效果不在现有 `KNOWN_EFFECTS`，需要在 `effect_system.js` 实现并加入白名单（同时更新数据校验）。每条给出建议结算口径：

| 新效果 | 语义 | 建议结算 |
|---|---|---|
| `taunt(n)` | 嘲讽 n 秒，强制敌方普攻/单体技能指向自己 | 状态 buff，`is_debuff=false`，期间敌方目标解析强制改为自己 |
| `expose` | 把目标（敌后排）移到前排并标记，受到的伤害+X% | 位移到前排 + 挂易伤 debuff |
| `dash_back` | 自身突进到敌后排 | 位移到敌后排身位，无视前排阻挡 |
| `silence(n)` | 沉默 n 秒：不能放大招/小技能（可普攻） | 状态 debuff，`can_use_skill` 判 false |
| `shield(v)` | 获得吸收盾，吸收 v×最大生命伤害 | 独立护盾池，先于 hp 扣除 |
| `lifesteal(v)` | 造成伤害的 v 比例回血 | 伤害事件后按比例 `heal` |
| `revive(v)` | 复活最近阵亡友军，回复 v 比例生命 | 取 `_player_deaths` 最近者，重置 hp=v×max |
| `energy_drain(v)` | 抽目标 v 怒给己方怒最低者 | `target.gain_rage(-v)` + 己方 `gain_rage(+v)` |
| `haste/slow(target,n)` | 攻速增减（攻击间隔缩放）n 秒 | 修改 `atk_interval` 乘区 |
| `act_now(n)` | 令 n 名友军立即行动 | 横版无 av，改为直接触发其 atk_timer 就绪 |
| `knockback(n)` | 击退 n 身位 | 位移，撞阻挡即停 |
| `invuln_dying(n)` | n 秒内锁血不死（最低 1 血） | `take_damage` 钳制到 1 |
| `heal_cut(v)` | 减疗：目标受到治疗-v 比例 | 治疗事件乘 (1-v) |

> 红线提醒：`KNOWN_EFFECTS` 是数据校验依据，加新效果必须同步加白名单 + 单测，未知效果仍要报错。
