## 0. 一句话定位

水浒第一神偷、地贼星「鼓上蚤」——一个**高机动、高闪避、专切后排**的敏捷刺客型盗贼。视觉上要「轻、巧、贼、俏」，与重甲猛汉（鲁智深 / 李逵）形成强烈反差。

**核心视觉母题：突进、残影、轻盈、狡黠。**

## 3. 外貌特征（国漫卡通）

- **体型**：瘦小精悍，约 7.5 头身（卡通偏修长），明显区别于壮汉单位。
- **脸**：尖下颌、机灵小眼、常带狡黠笑；眉上可加一道小疤添江湖气。
- **发**：束发或短发包巾，利落不拖沓。
- **年龄感**：青年精壮（肌肉紧实但不夸张，区别于少年感）。
- **配色建议色板**：
  - 主色：墨青 / 夜蓝（夜行）
  - 点缀：朱红（腰带 / 护腕，呼应「鼓」与「火」）
  - 暗部：炭灰；高光：月白
  - 禁用：大面积金 / 重甲色（属高级将星专属）

## 4. 服饰与装备

- 夜行紧身短打（分层），便于大幅度动作。
- **蹑踪软底快靴**（强调轻功，是身份符号）。
- 轻甲：护腕 + 皮护腰（非板甲）。
- 武器：短刀（腰间或背后单刀）。
- 道具彩蛋：腰挂一卷「甲」（呼应徐宁盗甲羁绊）；袖中暗器小镖。
- 标志姿态：单手扶刀、身体微侧、重心在前脚（刺客预备）。

## 5. 美术方向参考（国漫卡通）

- 基调：偏《雾山五行》的写意线条 + 《刺客伍六七》的俏皮角色感。
- 线条：干净利落、动态适度夸张。
- 渲染：卡通着色（cel-shading），少写实阴影 —— 契合 Three.js 用 toon material。
- 表情库：机灵 / 狡黠 / 得意 / 警觉 四态（立绘与动画复用）。

## 6. 模型制作规格（对接游戏）

- **格式**：GLB，覆盖 `assets/models/shiqian.glb`（已被 `side_battle.js` 自动加载）。
- **朝向**：正面朝 **+x（敌方方向）**，与现有加载逻辑一致。
- **身高**：游戏自动缩放至 ~1.1 单位，模型比例正确即可，无需精确绝对尺寸。
- **面数**：手游建议 ≤ 3 万面，贴图 ≤ 2K。
- **骨骼**：须在 Blender 用 Auto-Rig Pro / Rigify **重绑**（AI 生成骨骼命名混乱，不可直接用）。
- **动画清单**（绑定 + 动画阶段）：
  - `idle` 待机（轻浮、重心微晃，显狡黠）
  - `attack` 普攻（短刀突刺）
  - `skill` 飞檐走壁（腾跃突进）
  - `ult` 掠影（残影刺杀）
  - `hit` 受击 / `dead` 倒地
- **材质**：Three.js 侧建议 toon / Matcap，贴合国漫卡通。

## 7. 与现有战斗机制的对应校验

- `dash_back`（突进后排）：模型需留足「前冲 / 腾跃」动画空间。
- `steal_buff`（偷增益）：身上可预留「偷到 buff 的光点」特效位。
- `sure_hit` / `silence`：大招表现「必中 + 封口」。
- 高 `dodge`：`idle` / `hit` 强调闪避残影。

## 8. 设定确认项（2026-08-04 已拍板）

1. 武器：**单短刀**（以 CSV 实写为准，不追加哨棒）。
2. 「盗甲」彩蛋：**保留**（腰挂一卷甲，呼应徐宁羁绊）。
3. 年龄感：**青年精壮**（肌肉紧实、利落，非少年）。
