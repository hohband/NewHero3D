## 3. 外貌与配色

- **体型**：**全队最瘦长**，约 8 头身，肩窄腰细、四肢修长（弓手体型），明显比林冲更轻。
- **脸**：清俊青年，剑眉朗目、鼻梁挺直，神情沉静专注（不怒自威的「准」）。
- **发**：束发高马尾或发髻配小冠，鬓角干净。
- **配色**：
  - 主色：银白（轻甲）／靛青（战袍）
  - 点缀：**绛红箭羽**（唯一的暖色，视觉焦点）
  - 金属：亮银（非金）
  - 禁用：重金、重甲厚裙（他是轻装狙击手）

## 4. 服饰与装备

- **轻甲**：胸甲 + 肩甲（板片少、贴合），便于开弓。
- **靛青战袍**，下摆收窄不拖地（避免影响箭步）。
- **护腕（左臂加大护臂）**——弓手的标志性装备。
- **武器：天地日月弓**——**长弓**，弓臂线条完整、弓弦可见；弓身可作双色（弓背深漆、弓腹浅木）。
- **箭囊/箭袋**：背后或右侧腰挂，**箭羽为绛红色**，一眼可辨。
- **细节彩蛋**：左手拇指戴扳指。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。
- **长弓是最大风险项**：弓臂细且弓弦更细，图生 3D 极易断裂或糊成一坨。因此提示词要求「弓臂线条清晰、弓弦可见」，**并且弓与身体必须留间隙**；若生成结果弓形残缺，备选方案是**只保留弓臂、去掉弓弦**（弦在 Three.js 侧用一根细圆柱补，成本远低于重跑）。
- 身高归一化后**不做体型补偿**：瘦长是他的识别特征，但游戏内所有单位都缩到同一身高，体型差靠比例（肩宽/粗细）体现，不要靠绝对高度。
- 目标：GLB → 本地 Blender 绑骨（20 骨 + idle/attack/hit/skill），压贴图 1024²，覆盖 `assets/models/hua_rong.glb`。
- 天赋远程单位：`side_battle.js` 中弹道表现沿用现有远程弹道，不新增逻辑。
