## 0. 一句话定位

地恶星「没面目」——一生只会摔人的相扑力士。视觉核心是「**空手**」：**全队唯一没有兵器的人**，扎马步、双拳当胸，一身横练的厚肉就是他全部的武器。

## 1. 基础信息（取自 CSV）

| 字段 | 值 | 设计含义 |
|------|-----|----------|
| 姓名 / 绰号 | 焦挺 / 没面目 | 「没面目」→ **面瘫、平板无表情**，不是「没脸见人」 |
| 星位 / 品质 | 地恶星 / blue（蓝） | 蓝品 → 可用一处彩色（暗红腰绳），但仍朴素 |
| 职业 | infantry（步行近战） | 近战缠斗 |
| hp / def | 620 / 62 | 肉厚耐打（铁布衫） |
| atk | 85 | 中上 |
| spd | 76 | 中上（相扑的爆发力） |
| 武器 | **铁拳** | ⚠️ **无实体兵器** —— 相扑摔投，**全队唯一** |
| 大招 | 无相扑（expose + 眩晕） | 把敌人**暴露到前排并甩晕** |
| 羁绊 | 李逵 · 绞肉机 | ⚠️ 与李逵区分：**无兵器 + 扎马步 + 面瘫 + 宽腰带** |

## 2. 战斗风格 → 视觉映射

| 技能 | 机制 | 视觉关键词 |
|------|------|-----------|
| 相扑绝技（小技能） | 伤害 + 换位 + 眩晕 1 回合 | 抓抱、摔投 |
| 摔投（被动） | 受击 30% 概率反打 20% | 缠抱 |
| 铁布衫（被动） | 每回合防御 +10% | 横练厚肉、沉肩 |
| 无相扑（大招） | 暴露 + 眩晕 | 把敌人甩出去 |

**核心视觉母题：赤手空拳、扎马步、宽腰带、面瘫厚肉。**

## 3. 外貌与配色

- **体型**：**壮实横练**，约 **6.5 头身** —— 肩宽背厚，**腰腹与大腿尤其粗壮**（相扑的下盘），但**上半身不做李逵那种「胸背厚到夸张」的程度**。
  - 区分点：**李逵是「到处都厚」，焦挺是「下盘比上身更厚」**。
- **脸**：三十岁上下，**面无表情、平板无神**（「没面目」）—— 宽脸、单眼皮、嘴唇抿成一条线，眼神空。
- **发**：头发极短（近似寸头），不戴巾。
- **配色**：
  - 主色：**深靛蓝**（短打）
  - 辅色：**土褐**（宽腰带）
  - 点缀：**暗红**（腰带绳结）
  - 肤色：**大面积裸露的肩臂**（本批唯一露肤面积大的角色）
  - 金属：**无**

## 4. 服饰与装备

- **深靛蓝粗布短打**：**上身只穿一件敞襟的无袖短褂（袒露双肩与手臂）**，腰间缠一条**厚土褐色宽布腰带（相扑式）**，下身穿**及膝短裤**。
  - ⚠️ **不做兜裆布** —— 用「短褂 + 宽腰带 + 及膝短裤」表达相扑力士装扮，避免暴露式设计。
- **小腿绑布，赤足**（相扑的脚要抓地）。
- **无任何兵器、无护甲**；护具只有**双腕缠布**。
- **姿态：直立站姿、双脚近乎并拢（两脚间距不超过一个脚掌宽）、双膝微微弯曲、重心略下沉、上身略微前倾，双拳握于胸前（相扑起手式）**。
  - ⚠️ **双手必须是空的** —— 这是本批最重要的一条造型指令。
  - ⚠️ **不许扎马步、不许双膝外开、不许把双脚分开站立** —— 这是**硬约束，不是审美偏好**，理由见 §6 风险项 3。
  - 相扑的读感改由「短褂 + 厚宽腰带 + 胸前的空拳 + 略沉的肩」承担，**不靠开腿**。
- **细节彩蛋**：颈后搭一条擦汗的布巾（**不手持**）。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**。
- ⭐ **本批最不该出问题的一个**：**没有兵器 → 不存在「兵器远端离手被骨头牵走」这个本批最大的风险**。他在管线里的作用是**对照组** —— 若他的 `PROP_CLUSTERS` 也出现异常簇，说明那些簇是**误抓了身体部件**，而不是兵器问题，这个信号对判断其他 9 人非常有用。
- **风险项 1：容易被生成成「拎着兵器的大力士」。** → 提示词双重写死「双手是空的、不得出现任何兵器」。
- **风险项 2：与李逵撞。** → 李逵是**双斧 + 赤膊 + 怒目络腮胡**；焦挺是**无兵器 + 无袖短褂 + 面瘫 + 相扑宽腰带**。
- **风险项 3（本批已改掉，勿回退）：扎马步会让双脚落到 x≈±0.15 以上，而硬编码骨架的腿骨在 x=±0.055、脚骨在 ±0.06。** 这与鲁智深当年「下蹲姿双腿落在 ±0.2 → 绑骨必崩」属同一类问题，且比上一批李逵 / 扈三娘的「站姿偏宽」更严重（那两位只是「偏宽」，马步是**结构性外开**）。
  → **本批姿态已改为「双脚近乎并拢 + 双膝微屈 + 重心略沉 + 上身微前倾」**，相扑的读感由短褂、宽腰带与胸前的空拳承担。
  - ⚠️ 这是**硬约束**：不要因为「马步更像相扑」而回退这一条。
- 布料控制：**短褂 + 短裤，无下摆、无披风，露肤面积大反而有利于布料扭形风险降到最低**。
