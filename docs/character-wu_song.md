## 0. 一句话定位

天伤星「行者」——**全队最高攻击的连击型近战**，四段醉拳把精英与 BOSS 拆成碎片。视觉核心是「**狠**」：头陀行者的清冷装束下，是一双随时爆发的眼睛。

## 2. 战斗风格 → 视觉映射

| 技能 | 机制 | 视觉关键词 |
|------|------|-----------|
| 醉拳（小技能） | 重击精英 | 醉步晃身、力从腰发 |
| 醉打蒋门神（大招） | 四段连击 ×4 | **连环劈砍**、残影四连 |
| 醉打（被动） | 30% 追加一拳 | 补拳、不停手 |
| 以血还血（被动） | 受击 50% 还击 | 挨打冷笑、反手一刀 |

**核心视觉母题：双刀、醉步、连击、狠。**

## 3. 外貌与配色

- **体型**：精悍匀称，约 7.5 头身，比林冲略瘦、比鲁智深小两圈；肩背线条紧实（不是健美型，是练家子型）。
- **脸**：剑眉凤目、下颌线利落、鼻梁高挺；**神情冷而锐**，嘴角压着一点冷笑。
- **发**：**散发（头陀发）+ 额箍**——这是「行者」身份的关键特征，必须清晰。
- **配色**：
  - 主色：皂黑（直裰）／靛蓝（内衬）
  - 点缀：月白（束带）、皮革棕（护腕）
  - 金属：镔铁冷灰（刀身雪花纹）
  - 禁用：艳色大块（保持行者清冷基调）

## 4. 服饰与装备

- **头陀装束**：皂布直裰、额上铁箍、散发垂落。
- **胸前皮质束具 + 一串粗大数珠**（原著有「人顶骨数珠」，此处以**素色骨珠/念珠**表达，不做血腥处理）。
- **护腕 + 布条缠小臂**，便于双刀发力。
- **武器：一对雪花镔铁戒刀**——刀身较短直、无长柄，**刃面有雪花状镔铁纹**，与林冲长矛、鲁智深禅杖形成明确差异。
- **细节彩蛋**：腰后斜插一顶旧头巾。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**；双刀需**左右分开且不与躯干重叠**（成对细长物体是本批最易粘连的部位）。
- 散发与额箍的细节在 1024² 贴图下会糊，**以轮廓可辨为准**，不追求发丝。
- 目标：GLB → 本地 Blender 绑骨（20 骨 + idle/attack/hit/skill），压贴图 1024²，覆盖 `assets/models/wu_song.glb`。
- 大招「四段连击」在动画上表现为快速连劈（16 帧 attack 内做压缩，不要拉长）。
