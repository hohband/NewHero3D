## 0. 一句话定位

天巧星「浪子」——**全队最俊的一个，也是身法最飘的一个**。视觉核心是「**巧**」：一身花绣、手持川弩，动作是「突进—回身」的浪子身法。

## 2. 战斗风格 → 视觉映射

| 技能 | 机制 | 视觉关键词 |

**核心视觉母题：花绣、川弩、藕白衣、俊。**

## 3. 外貌与配色

- **体型**：**修长健美的青年**，约 8 头身，宽肩窄腰、肌肉线条流畅但不臃肿 —— 与花荣的「瘦长」区分：**花荣是细，燕青是韧**。
- **脸**：二十余岁，**眉清目秀、唇形饱满、笑起来的样子**（神情是自信从容的潇洒，不是武将的杀气）。
- **发**：黑发束顶，**不留冠**（一缕碎发垂于额前），干净利落。
- **配色**：
  - 主色：**藕白 / 月白**（贴身短打）
  - 辅色：**石青**（外褂、护腕）
  - 图案：**墨色花绣**（覆盖右臂与右胸，藤蔓／云纹样式）
  - 金属：暗银（弩机）
  - 禁用：重金、重甲、朱红大面积

## 4. 服饰与装备

- **藕白贴身短打**，外罩**石青敞怀短褂**（敞着，露出右胸与右臂的花绣）。
- **窄幅腰带**，束脚裤 + **轻便短靴**（便于突进）。
- **护腕一对**（暗银包边）。
- **武器：川弩**——**横置的弩机，弩臂宽、弩身短、带上弦的弩弦与一支已装填的弩箭**，**单手持弩横于身前、与胸口留出明显间隙**（不要贴胸、不要竖拿像弓）。
- **细节彩蛋**：弩机上有一道石青缠绳；左耳一枚小银环。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**。
- **风险项 1：川弩的弦与箭**。弩弦细、弩箭细，图生 3D 极易断裂或糊成一坨 → 提示词要求「弩弦可见」，**若结果残缺，备选方案是只保留弩臂与弩身、去掉弦与箭**（弦可在 Three.js 侧用细圆柱补，成本远低于重跑）——与花荣的弓同一处置策略。
- **风险项 2：花绣**。刺青是纯表面纹样、无几何起伏，图生 3D **只能靠贴图承载**。**这一点是好消息**：几何不受影响，只要混元的 Paint 阶段没把纹样洗掉就能保住。→ 复核时专门看右臂。
- **风险项 3：敞怀短褂**。两片布料与躯干相邻，可能被合成一体 → 敞怀幅度不宜过大，**不要长下摆**。
- 身高归一化后不作体型补偿：**修长靠肩宽与四肢比例体现，不靠绝对高度**。
- 目标：`tools/mesh_clean_islands.py` → `tools/blender_rig_character.py` → 覆盖 `assets/models/yan_qing.glb`。
