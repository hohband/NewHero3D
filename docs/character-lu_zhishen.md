## 0. 一句话定位

天孤星「花和尚」——**全场最壮的重甲先锋**，以肉身扛线、以蛮力清场。视觉核心是「**豪**」：满身花绣、敞怀大笑、禅杖一举便是横扫千军。

**核心视觉母题：巨力、禅杖、花绣、豪笑。**

## 3. 外貌与配色

- **体型**：**全场最壮**，约 7 头身但极宽（肩宽 ≈ 2.2 个头宽），胸背厚实、四肢短粗有力；与武松（匀称）和林冲（修长）形成阶梯式反差。
- **脸**：方圆脸、浓眉大眼、络腮络胡、鼻宽口阔；**开口大笑**，一眼看去是个豪爽莽汉而非恶人。
- **发**：光头（僧），头顶可留戒疤三点。
- **花绣**：右侧肩背至手臂大片**青绿色花绣（莲花／云纹／兽纹）**，是「花和尚」的招牌，必须清晰可见。
- **配色**：
  - 主色：赭石褐（直裰）／墨黑（裈裤）
  - 点缀：**青绿花绣**、铜黄（佛珠、禅杖环）
  - 皮肤：健康黝黑
  - 禁用：精细金饰（他是粗人，不华贵）

## 4. 服饰与装备

- **粗布直裰半敞**，露出胸膛与花绣；腰间麻绳束带。
- **脖挂粗大佛珠**（木质大珠），可作身份符号。
- **绑腿 + 草鞋/粗靴**（非精甲靴）。
- **护具极简**：只有护腕与肩部皮甲片 → 靠肉身抗，符合 block 22 的「硬扛」表现。
- **武器：水磨禅杖**——长柄（约身高的 1.3 倍），一端月牙铲、一端僧杖，杖身铜环叮当。
- **细节彩蛋**：腰间挂一个酒葫芦。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切，禅杖竖直持握且与身体留间隙**。
- 体型是本批最大者，图生 3D 后的归一化会把它缩到 1.75 单位——**不要因此修改设定比例**，体型差由游戏层缩放常量处理。
- 目标：GLB → 本地 Blender 绑骨（20 骨 + idle/attack/hit/skill），压贴图 1024²，覆盖 `assets/models/lu_zhishen.glb`。
- 动作幅度需克制（挥击 ≤0.8rad，靠腿部与腰部发力表现重量），原因见 `tools/blender_rig_character.py` 权重限制。
