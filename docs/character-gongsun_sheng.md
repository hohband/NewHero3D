## 0. 一句话定位

天闲星「入云龙」——**全队唯一的橙色策士**，也是唯一的老人。视觉核心是「**道**」：白须道袍、袖手而立，一柄松纹古定剑，雷法从袖底起。

## 3. 外貌与配色

- **体型**：**清癯高瘦的老者**，约 8 头身，肩窄、无肌肉线条，与鲁智深的「壮硕巨汉」和秦明的「魁梧」形成对照。
- **脸**：六十岁以上，**长须垂胸、须眉皆白**，眉长入鬓，眼神清亮不浑浊（是修道有成而非衰朽）。
- **发/冠**：**道冠**（束发于顶，配小玉冠），鬓白。
- **配色**：
  - 主色：**靛蓝道袍** + 月白内衬
  - 点缀：**金线雷纹**（袖口、前襟、腰带各一道，克制）
  - 符文：**朱砂黄符**
  - 金属：古铜（剑鞘）+ 银（须发）
  - 禁用：重甲、护肩、大面积金饰（他是策士，不是武将）

## 4. 服饰与装备

- **靛蓝宽袖道袍**，前襟与袖口各一道金线雷纹，下摆到脚踝、开衩便于行走。
- **腰带束黄符袋**，腰间悬一枚木牌（道门信物）。
- **道冠 + 长须**：这是与吴用最直接的区分手段。
- **武器：松纹古定剑**——剑身有松枝状暗纹，古铜剑鞘，**剑横托于身侧前方、与身体保持明显间隙**（不要贴腿竖插，会与袍角粘连）。
- **细节彩蛋**：左手袖口露半截朱砂符，指间极细的蓝白电光。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**（依据 §8.2 实测增益 ≈ 0）。
- **风险项 1：剑与袍角粘连**。宽袖道袍下摆宽大，剑若贴身竖持会与袍角在网格上融成一体、无法分离。→ 提示词已强制「剑与身体留出明显间隙」；若生成结果仍粘连，改为**剑横举于身前**再出一版。
- **风险项 2：白须**。图生 3D 对细长片状物（须、眉）易糊 → 须作「成束的中等粗细」，不要求根根分明。
- 身高归一化后不作体型补偿：清癯是他的识别特征，但游戏内所有单位缩到同一身高，**清瘦靠肩宽与体积体现，不靠绝对高度**。
- 目标：GLB → `tools/mesh_clean_islands.py` 清碎块 → `tools/blender_rig_character.py` 绑骨（20 骨 + idle/attack/hit/skill），压贴图 1024²，覆盖 `assets/models/gongsun_sheng.glb`。
- ⚠️ 兵器识别仍受「骨架姿势不匹配」限制（`docs/pipeline-3d-asset.md` §8.4），本批**接受**兵器按最近骨权重（挥击时轻微弯曲）。**不因此改姿势** —— 姿势必须保持直立，否则第 5 步整体崩。
