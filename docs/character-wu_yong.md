## 0. 一句话定位

天机星「智多星」——**全队最不像武将的一个**。视觉核心是「**文**」：纶巾羽扇、瘦到几乎没有体积，两条铜链垂在身侧。全队唯一**完全无甲**角色。

## 2. 战斗风格 → 视觉映射

| 技能 | 机制 | 视觉关键词 |
|------|------|-----------|
| 扰乱军心（小技能） | 降谋略 + 概率束缚 | 铜链抖出弧线 |
| 调虎离山（大招） | 强制敌将换位 | **铜链牵拉、以链代绳** |
| 智多星（被动） | 攻击降对手谋略 | 摇扇、垂目 |
| 谋定后动（被动） | 每回合谋略 +12% | 一手负后、胸有成竹 |

**核心视觉母题：纶巾、羽扇、两条铜链、无甲。**

## 3. 外貌与配色

- **体型**：**全队最瘦**，约 8 头身，肩极窄、四肢细长，**完全没有护具的轮廓**（与花荣的「瘦长弓手」区分：花荣有轻甲与护臂，吴用是布衣）。
- **脸**：三十岁上下，**清瘦白净、下巴略尖**，细长眼、薄唇，神情是从容的算计（不阴鸷）。
- **发/冠**：**黑色长发束起，戴纶巾**（文士巾，与道冠、武将盔都不同）。
- **配色**：
  - 主色：**鸦青儒衫** + 月白内衬
  - 点缀：**黄铜**（两条铜链的唯一亮色）
  - 配饰：玉色扇坠、腰间书卷
  - 禁用：任何金属甲片、护肩、护腕、金饰

## 4. 服饰与装备

- **鸦青交领儒衫**，宽袖但不拖地，下摆及小腿，开衩。
- **腰间系青绦**，挂一枚玉扇坠与一卷竹简。
- **纶巾 + 羽扇**：羽扇是「文」的第二识别符（第一是脸）。
- **武器：两条铜链**——两人高的短铜链，**双手各持一条，自然垂落于身体两侧前方，链身与身体之间保持明显间隙**（不要缠绕在身上）。
- **细节彩蛋**：链端各缀一枚小铜铃。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**。
- **风险项 1：铜链太细**。链是细长圆管，图生 3D 极易断成几截或糊成一坨。→ 提示词要求「短铜链、链环粗壮可辨」；若生成结果碎裂，**备选方案：把铜链改为「两条较粗的铜制短杖/铜环索」**再出一版。**不要为了链把整张图重出**。
- **风险项 2：双手各持一物（链 + 扇）**。管线硬前置是「只出现一件兵器」——**扇不是兵器，但要写死「除两条铜链外没有任何刀剑枪棒」，防止模型自行加戏**。
- **优势项**：双手持链 = **双持外张**，与武松双刀同类，是现有 `blender_rig_character.py` **能自动识别兵器**的形态。本批 8 人里识别前景最好的两个之一（另一个是李逵）。
- 身高归一化后不作体型补偿：**瘦靠肩宽与体积体现，不靠绝对高度**。
- 目标：`tools/mesh_clean_islands.py` → `tools/blender_rig_character.py` → 覆盖 `assets/models/wu_yong.glb`。
