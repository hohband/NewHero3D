## 0. 一句话定位

地微星「矮脚虎」——又矮又凶的愣头青刀手，扈三娘的丈夫。视觉核心是「**矮而薄**」：约 7 头身、精瘦有筋，双刀向两侧外张、重心压得很低，一副随时要扑上来的样子。

## 2. 战斗风格 → 视觉映射

| 技能 | 机制 | 视觉关键词 |
|------|------|-----------|

**核心视觉母题：矮小精悍、双刀外张、低重心、凶悍愣直。**

## 3. 外貌与配色

- **体型**：**矮但精瘦**，约 **7 头身**（头身比正常，只是绝对身高矮一档），肩窄腰细，**上身肌肉线条清晰但绝不厚重**。
  - ⚠️ **与李逵的关键区分（必须守住）**：李逵是 **6 头身、胸背极厚、赤膊**；王英是 **7 头身、精瘦、着衣**。
- **脸**：二十六七岁，**眉短眼亮、嘴角下撇、下颌偏尖**，神情是「不服就干」的凶，带一点愣。
- **发**：黑发扎成**短冲天辫 / 短马尾**（乱、微微翘起），额前散几缕。
- **配色**：
  - 主色：**靛青**（短打劲装）
  - 辅色：**暗褐**（革带 / 护腕）
  - 点缀：**赤红**（束带与刀柄缠绳，全画唯一暖色）
  - 金属：**铁灰**（哑光）
  - **禁用**：金饰、华丽纹样、暴露式设计

## 4. 服饰与装备

- **靛青色短打劲装**（紧身、袖口束紧），外罩**无袖轻革甲**（护胸一片 + 双肩小护片）。
- **窄革腰带 + 布绑腿 + 短靴**（便于突进，不做长靴）。
- **武器：双刀** —— **双手各持一柄短刀，向身体两侧外张**（与武松、扈三娘同类姿态，**不要交叉于胸前**），刀身与躯干之间留出明显可见的间隙。
- **细节彩蛋**：双刀柄缠赤红绳；腰间别一枚**小铜哨**（哨聚山寨，不手持）。
- ⚠️ **无盾、无披风**。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**。
- **优势项：双刀外张 + 垂臂握在腰胯高度** —— 与武松同类（已实测成功）。
  - ⚠️ **别把「同批扈三娘也双刀外张却失败了」误读成双刀形态有问题**：她栽在**刀尖窜进高衩下摆**（洪泛长成 0.374×0.353×0.175 的布块、长细比 2.1 被丢弃），不是双刀本身。王英**无下摆、无裙、无披风**，风险远低于她。
- **风险项 1：矮个容易被生成成「侏儒 / 孩童」。** → 提示词已写「成年男子、身高中等偏矮、约七头身」，并明确排除孩童。
- **风险项 2：与李逵撞（都矮）。** → **体厚互斥**：李逵赤膊 + 胸背极厚 + 双斧；王英着衣 + 精瘦 + 双刀。
- **风险项 3：与武松撞（都是双刀外张）。** → 体型差异极大（武松是橙品高壮打虎英雄，王英是蓝品矮瘦愣头青），不会混。
- 布料控制：**短打 + 护片，无下摆、无披风**（规避多骨共牵扭形）。
