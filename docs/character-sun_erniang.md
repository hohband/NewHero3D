地壮星「母夜叉」——十字坡黑店的老板娘，笑里藏刀的女掌柜。视觉核心是「**江湖**」：赭红围裙、袖口挽起、柳叶双刀外张，一身市井杀气压过脂粉气。

## 3. 外貌与配色

- **体型**：**女性、约 7.5 头身**，体态是「干活练出来的结实」—— **手臂有肉有力、肩背宽厚、腰身粗实**，绝不柔弱、不纤细。
  - ⚠️ **与扈三娘的关键区分（必须守住）**：扈三娘是**轻甲英气女将**（青碧、高马尾、身姿挺拔、贵族气）；孙二娘是**市井草莽老板娘**（赭红围裙、圆髻、稍显粗壮、市井气）。
- **脸**：三十岁上下，**眉粗色浓、眼梢上挑、嘴唇偏厚、颧骨高**，笑起来带着狠劲（「笑面夜叉」）。
- **发**：黑发在脑后挽成一个**松散的圆髻**（**不是高马尾**），用一支木簪别住，鬓角散几缕碎发。
- **配色**：
  - 主色：**赭石红 / 暗红**（围裙与头巾）
  - 辅色：**土黄褐**（粗布衣）
  - 点缀：**瓷青**（小酒壶与腰带，唯一的冷色）
  - 金属：**暗铁**（刀身）
  - **禁用**：粉色、金饰、暴露式设计、华丽纹样

## 4. 服饰与装备

- **土黄褐色粗布上衣，双袖挽至肘上**（利落、露小臂）；外面系一条**赭红色粗布围裙**（从胸下到膝上、**贴身、不开大摆**）。
- **宽布腰带**束腰；下身穿**深褐粗布裤 + 布绑腿 + 包头皮靴**。
- ⚠️ **不要给她护甲** —— 黑店老板娘不穿甲。护具只有**布护腕 + 皮护臂**。
- **武器：柳叶双刀** —— 刀刃形如柳叶（细长微弯）。**双手各持一柄，向身体两侧略微向上外张（接近水平）**，不要交叉于胸前。
  - ⚠️ **刀身与躯干、与围裙之间都要留出明显可见的间隙**；**刀尖绝不能垂向围裙或下摆**。理由见 §6 风险项 1 —— 这是上一批扈三娘失败的确切剖面。
- **细节彩蛋**：腰间挂一只**小陶酒壶**（蒙汗药的来源，**不手持**）。

## 6. 3D 建模规格

- 面向图生 3D 单图输入：**正面全身、不裁切**。本批**不做多视图**。
- **优势项：双刀外张** —— 与武松同类姿态（武松双刀已实测成功）。
- **风险项 1（本角色最高风险）：她与上一批失败的扈三娘是同一个剖面** —— **短弯刀 + 邻近的下摆布料**。扈三娘的实测结果：种子 178（比成功的戴宗还多），但洪泛从柳叶刀尖**窜进了高衩下摆**，长成 0.374×0.353×0.175 的一坨布，长细比 2.1 < 3.0 → **被丢弃**。秦明同理（从狼牙棒窜进朱红重甲，吞 12157 顶点）。
  → 对策（已写进 §4 / §5）：**双刀向两侧略向上外张、接近水平，刀尖远离围裙**；围裙贴身、及膝、不开大摆；明确要求刀身与身体、与围裙都有可见间隙（让洪泛的 `_d_body>0.12` 阻断生效）。
  → 跑完看 `PROP_CLUSTERS`：理想结果是两侧各长出一个细长簇（长细比远大于 3）。若出现「丢弃」且 `dims` 的两个大值都不小，就是布料被吞了 —— 说明刀离围裙太近，**下一版把刀再抬高一点**。
- **风险项 2：女性 + 围裙 → 容易被生成成「家庭主妇」，丢失江湖狠劲。** → 提示词已强化「肩背宽厚、手臂圆实、笑起来带狠劲、市井人物」。
- **风险项 3：与扈三娘撞（同为女性）。** → **发髻 vs 高马尾、围裙 vs 战甲、赭红 vs 青碧、粗实 vs 挺拔**。
- **风险项 4：围裙布料面积较大** → 属「披风 / 下摆多骨共牵扭形」的灾区。→ 围裙**贴身、及膝、不开大摆**；**无披风、无长裙**。
- **风险项 5：她与扈三娘是本批唯二的女性样本。** 若女性体型在混元重建里表现差，这条结论会决定「女性角色能不能继续铺」。
